# Quranic Quest

Build me an app that does this



It’s an app based around Adthkar and reading Quran. You set yourself a daily target of how much Quran you want to read and what adthkar you want to do. Your socials, and other apps you choose stay blocked, until you have completed your target. It can have things like streaks, community challenges, and etc. like maybe shows a live community dhikr, or country vs country table or smthn. Can also create private groups amongst friends

To add on, each translation day can be split into lessons. Like Duolingo, so you read the tafsir/translation. Then get quizzed on what you learn

Does something like this exist?

It should go in chronological order, the lessons. So once you finish all lessons, you finish the Quran as well
